# 留一点时间，慢慢写。

一个安静的地方，用来记录、连接和展开想法。

## 文件始终属于你

SlipsMD 直接编辑普通的 **Markdown 文件**。打开一个文件夹，就可以开始写作，无需账号。

你可以打开 [灵感笔记](Ideas.md)，在右侧继续阅读；按住 Ctrl 点击 [阅读清单](Reading.md)，在独立窗口中展开。

## 先记录，稍后整理

- 打开左侧的收集箱，记下一个尚未成形的想法。
- 稍后再将它整理到当前笔记。
- 切换亮色或暗色，让界面适应你的环境。

| 操作 | 快捷键 |
| --- | --- |
| 保存笔记 | Ctrl + S |
| 新建独立窗口 | Ctrl + Shift + N |
| 收集想法 | Ctrl + Enter |

数学也可以留在文字里：$E = mc^2$。

> 不必先决定标题和分类，先把值得留下的内容写下来。
