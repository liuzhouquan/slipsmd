# TASK-005：Windows IME、真实 PicGo、安装向导与第三方同步环境人工验收

状态：Blocked（待真实 Windows 环境与人工操作）。负责人：agent（文档整理）／维护者（Windows 人工实测）。Issue / PR：待创建。

## 场景与范围

- **背景与目标**：依据 [progress.md](../../progress.md) 与 [validation.md](../../validation.md#仍需人工验证)，自动化桌面集成测试与模拟 HTTP PicGo 服务无法覆盖真实 Windows 中文输入法组合输入、真实 PicGo 图床、NSIS 安装向导及第三方同步客户端的文件锁定与冲突行为。本任务建立可审计、可逐项记录的人工验收规格与测试单，并在真实环境中完成执行与结论回填。
- **范围**：
  1. **Windows 中文输入法（IME）**：微软拼音与常用第三方输入法在实时预览与源码模式下的组合输入（composition）、候选框定位、跨行编辑、撤销／重做与链接补全交互。
  2. **真实 PicGo 与图床上传**：连接本机真实 PicGo 服务（默认 `http://127.0.0.1:36677/upload`），覆盖上传成功、代理／断网失败、`pending-images` 临时图片保留与重试／切回本地保存。
  3. **Windows 安装向导与系统集成**：验证 NSIS 安装包（自定义目录向导）与便携版 zip 的安装、启动、`.md` 文件关联、`io.slipsmd.desktop` 应用标识、旧版数据迁移与卸载行为。
  4. **第三方同步、缩放与多窗口资源**：在 OneDrive / Syncthing / Git checkout / 杀毒软件实时扫描下验证外部更新、编辑冲突保护与安全移动失败回退，并记录高 DPI 缩放、多显示器与 1/3/5 窗口资源占用。
- **非目标**：
  - 本任务本身不修改产品源码（`src/`）；验收中发现的缺陷单列修复任务或后续提交，不将推测修改写成已验证。
  - 严禁使用 Linux 模拟环境、Playwright 自动键入或本地模拟 PicGo 服务替代人工实测结果。
  - macOS 验收不纳入本轮 Windows 优先验收阻塞项，可在清单中单独保留 `未验证` 标注。
