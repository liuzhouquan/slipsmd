## 解析与快照边界

URL 源范围由已依赖的 @codemirror/lang-markdown 语法树提供；不全局替换文件名，不重序列化 Markdown。先解 Markdown 转义／实体，再区分未解 URI 的 fragment，最后解码路径；生成新路径时按段编码，并保留片段原始写法。

规划纯函数不访问文件系统；扫描器只用 fs 的目录、元数据、读取操作，单次保留一个文件正文，限制 10,000 篇、24 层、单篇 20 MiB、累计 64 MiB 和 10,000 项编辑，并限制单篇 URL／排除区段 20,000 项及诊断 1,000 项。扫描后再核对目录清单与文件元数据，变化／不可读时报告不完整；计划摘要绑定根目录、移动路径、全部已扫描文件摘要／身份／元数据及建议编辑。选择操作重新扫描后对比摘要，不跨计划复用 ID。
