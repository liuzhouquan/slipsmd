## 每次接手核对

1. main 的最新提交／已发布基线，任务 Issue／PR 是否已被认领或合并。
2. 对应 spec 的 AC、plan 的接口／文件范围，以及其他并行任务的依赖。
3. 当前 worktree、分支、准确 HEAD、未提交内容、已完成验证及尚未验证项。
4. 下一步、阻塞、实现者与独立审核者；不以聊天中的“已做完”替代代码／CI／PR 证据。
