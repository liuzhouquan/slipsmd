## 首版实施补充

用户确认界面更接近 Typora 的纯白简洁风格。当前不复用 Muya / MarkText 或 Files.md 源码；选择 CodeMirror 6 直接实现预览扩展。初版同文件重复打开聚焦原窗口，右侧内容可编辑不同文件。后续增强与未验证项见 README 和 validation.md。

## 快捷方式实施

用户要求继续开发，本轮推进已提出的 F09。入口保存在应用设置中，各窗口共享；只保存路径和类型，不复制笔记内容。文件入口保留当前工作区，目录入口切换工作区，Ctrl+点击在独立窗口打开。外部单文件不作为跨工作区双链能力；原生选择结果和已有授权路径是添加入口的来源。

## 阅读位置实施

继续补齐阶段 2 的各视图位置恢复。主区与右侧使用独立的窗口内缓存，保存最近 100 份笔记的正文锚点、偏移、选区及源码／预览模式；不缓存编辑器全文、不写笔记或全局设置。以正文锚点适应宽度变化，在初始 1.5 秒布局期间校正图片等引起的高度变化，用户操作立即终止自动校正。关闭窗口即清除；重启会话恢复留待后续设计。

## 文件操作实施

通过统一 DocumentStore 队列实施文件重命名和工作区内移动；按路径排序获取两条锁，Windows 队列键忽略大小写，防止对向移动死锁或同一目标的并发写入。源正文必须已保存且与磁盘版本一致，目标不得存在文件、活动会话或同路径恢复草稿。独占硬链接创建新名称后，再检查源文件身份和内容并移除旧名称，保留 BOM／换行和全部原始字节；删除旧名称失败时撤回仍属于本次操作且未改变的链接。此方式要求同一文件系统支持硬链接，不承诺与外部进程组成跨文件事务。

界面提交时暂停当前窗口编辑，成功后更新主／右侧视图、标题、历史和位置缓存，各窗口同步授权路径，固定入口保存到新路径。路径仅允许当前工作区内；单文件模式只允许同目录改名。当前不自动重写 Markdown 引用和相对图片，也不移动收集箱 Chat.md；操作前提示这些边界，避免额外批量改写个人笔记。

## 目录创建实施

补齐创建文件夹、目录内新建笔记和移动已有笔记的整理流程。新建与移动共享相对路径及真实父目录校验，不递归创建缺失的层级；目录使用独占 mkdir，新笔记使用 DocumentStore 队列和 wx 写入，避免覆盖与复用含恢复草稿的路径。创建文件夹不切换当前笔记；创建笔记前保存，成功后打开并聚焦新笔记。文件树通过一次性展开／定位目标，不在每次刷新时重置用户的展开状态。文件夹重命名、移动、删除和引用批量修复仍在后续范围。

## 标题锚点实施

阶段 2 链接导航增加可选 fragment。标题索引来自当前 CodeMirror 文本，按不可变文本对象缓存，正文编辑后再生成；使用 MarkdownIt 识别普通 ATX／Setext 标题，排除初始 YAML 与代码示例。ID 采用 README 中的 Unicode 规则和去重后缀，运行时生成，不往 Markdown 插入 ID。标题跳转替代原阅读位置恢复，避免两种定位相互覆盖；复用 1.5 秒布局校正窗口，按完整标题行避开右侧固定工具栏，处理虚拟区高度在下一帧变化的问题。主动滚动或输入立即停止校正。

导航位置统一保存路径及可选锚点。右侧返回／前进重新解析标题位置，Ctrl+点击通过受授权的 IPC 传递给新窗口或已有文件所有者。所有者窗口忙碌或有创建／移动对话框时暂存最新导航请求，待操作结束再执行，保留正在输入的表单。找不到标题保留原文并提示；当前不处理自定义 HTML ID、wiki 链接或块引用。

## 增量链接索引实施

同一真实工作区路径共享 LinkIndex，最后一个引用该根目录的窗口关闭或切换后释放。缓存按文件保存链接条目及磁盘身份／大小／纳秒级修改与状态时间，已打开文件则比较 DocumentStore 当前文本；关闭文件不保留独立原文缓存。每次查询仍枚举目录并核对元数据，避免仅依赖文件监听。监听、暂存、保存、创建与移动操作使关联条目失效；失效发生在扫描期间时，共享该扫描的查询会补做新一轮，不返回旧反链。

每工作区最多同时读取 8 份正文；周期性让出事件循环，避免纯内存笔记扫描占满微任务队列。无变化时复用正向链接和反向索引；变化时按文件树顺序重建反向映射，删除／不可读／无效／越界文件不得留下幽灵条目。缓存可随时重建，不保存到笔记或应用设置。性能报告记录合成工作区的实际读取／解析量及冷、热、单文件变更和四窗口并发查询耗时，不设置易受机器影响的毫秒门槛。
