# SlipsMD interface

Confirmed direction: Typora-like white, quiet, uncluttered. Mode: Operate / Read.

Use a white writing canvas, pale neutral sidebar and one muted teal accent. System UI fonts for controls and a readable serif/system CJK stack for the document. No decorative illustrations, cards, gradients, or web landing-page patterns. Thin separators define the file tree, document and related-note pane. Native window chrome remains intact.

The primary content is the actual Markdown document. Opening a folder/file, creating a note, capturing a thought, saving and opening a new window must remain discoverable. Theme has explicit light, dark and system modes. Status and failure messages must say whether content was saved. Toolbar controls have accessible labels, visible keyboard focus and generous hit targets. Secondary actions are in settings, not scattered over the writing surface.

Pinned shortcuts use the existing sidebar rows and separators. Keep the list above the current workspace, bounded in height so the file tree remains usable. File and folder icons distinguish targets; full paths appear on hover, and removing a shortcut never means deleting its target. Current-document and current-workspace pin actions share one outlined pin icon. Outside-workspace files are identified in the breadcrumb and retain their full path in the status bar.
